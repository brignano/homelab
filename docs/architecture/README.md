# Architecture, drawn from the repo

These pictures are generated by [Driftwood](https://github.com/brignano/driftwood) from the Compose files and the Caddyfile in this repo. Nothing here is hand-drawn, and nothing on the box is read.

- [`request-flow.svg`](request-flow.svg): how a request travels. Host network, Caddy, then the service each site name reaches.
- [`services.svg`](services.svg): every stack and service, with its networks and volumes.
- [`summary.md`](summary.md): counts, and what is reachable from the host network.
- [`routes.json`](routes.json): the Caddy site names and the service each one proxies to. Generated from `docker/proxy/Caddyfile`.

## Refresh

```bash
scripts/architecture.sh
```

Needs Node 20+. Run it after changing a Compose file or a Caddy site block, and commit the result. `driftwood.config.yaml` tells Driftwood where the routes are; `.driftwoodignore` leaves out the `mcp-budget` write overlay, which shares a Compose project with the file it extends.
