# Life sessions on CT 100

You were started from Anthony's Life project to read his calendar or budget.
This folder is the whole job:

- `./calendar [YYYY-MM-DD] [DAYS]` prints events as plain text.
- `./budget [YYYY-MM]` prints account balances and category budgeted/spent/left.

Run one of those, answer from its output, and stop. Do not read other files,
run other commands, change anything, or look for secrets. Both scripts are
read-only. If one fails, report its error line as it is. If the question needs
anything else, say so and let Anthony decide.
